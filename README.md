# مختبر الثغرات — ثلاث مراحل

مشروع تعليمي مبني من الصفر بواجهة عربية. جميع المستخدمين والفواتير وهميون، والثغرات مقصودة. شغّله على جهازك فقط ولا تنشره على خادم عام.

## التشغيل باستخدام Python

يتطلب Python 3.10 أو أحدث. لا يحتاج مكتبات إضافية أو اتصال إنترنت.

افتح الطرفية داخل مجلد المشروع وشغّل:

```powershell
python app.py
```

على ويندوز يمكن فتح `start-windows.bat` أيضًا. افتح المتصفح على http://127.0.0.1:8000 . للإيقاف اضغط Ctrl+C في الطرفية.

## التشغيل باستخدام Docker

يتطلب Docker مع حاويات Linux؛ على ويندوز شغّل Docker Desktop أولًا.

```powershell
docker compose up --build -d
```

افتح http://127.0.0.1:8000 . لإيقاف المختبر:

```powershell
docker compose down
```

أول بناء يحتاج إنترنت لتنزيل صورة Python. المنفذ مربوط بعنوان الجهاز المحلي 127.0.0.1 فقط. لا تغيّر هذا الربط إلى عنوان عام. التطبيق داخل الحاوية يعمل بمستخدم غير root وبنظام ملفات للقراءة فقط.

## التسليم بالفلاشة

انسخ مجلد المشروع كاملًا. على جهاز مثبت عليه Python يمكن التشغيل مباشرة دون إنترنت. الفلاشة وحدها لا تثبّت Python أو Docker.

إذا جهاز العرض فيه Docker لكن لا يوجد إنترنت، ابنِ الصورة على جهاز متصل بالإنترنت وبنفس معمارية جهاز العرض، ثم احفظها على الفلاشة:

```powershell
docker compose build
docker save -o three-level-lab-image.tar three-level-lab:local
```

على جهاز العرض افتح الطرفية داخل مجلد المشروع بعد نسخ ملف الصورة إليه:

```powershell
docker load -i three-level-lab-image.tar
docker compose up -d --no-build
```

## محتويات المشروع

- `app.py`: الخادم، الواجهة، والثغرات الثلاث؛ باستخدام مكتبة Python القياسية وSQLite.
- `Dockerfile` و`compose.yaml`: إعداد الحاوية.
- `start-windows.bat`: تشغيل Python على ويندوز.
- `SOLUTIONS.md`: الحلول وتفسير الثغرات وطرق المعالجة؛ مخصص للمشرف.
- `test_lab.py`: اختبارات فعلية لمسارات HTTP والحلول.

## طريقة العرض

1. افتح الرئيسية واشرح أن هذا متجر تجريبي بثلاث مراحل مستقلة.
2. حل كل مرحلة من المتصفح ثم أدخل رمز النجاح في حقل التحقق.
3. اشرح سبب الثغرة وكيف تمنعها في تطبيق حقيقي، باستخدام ملف الحلول.

هوية المستخدم في مرحلة الصلاحيات ثابتة للتبسيط ولا توجد منظومة تسجيل دخول. لا تُحفظ النتائج أو محاولات اللاعبين. قاعدة بيانات مرحلة SQL تُنشأ في الذاكرة لكل طلب، فلا تحتاج إعادة ضبط. عرض الشفرة أو ملف الحلول يكشف الرموز؛ أثناء التقييم أعطِ اللاعب وصول المتصفح فقط، واحتفظ بالمصدر للمناقشة مع المدرّس.
